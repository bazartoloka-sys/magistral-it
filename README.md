# magistral-it.com

Сайт Magistral IT: історія-комікс, намальована олівцем. Статичний, без збірки.

## Сторінки
- `/` — вибір мови (Цифровий Гефест розбиває монітор, кубики UA/EN/PL). Вибір запам'ятовується; `/#choose` завжди показує сцену.
- `/ua/` — історія Василя, розділи 1–7.
- `/ua/cases/` — кейси: Базар Толока, Голосник.
- `/ua/order/` — заглушка анкети (анкета + відправка в Голосник — наступний етап).
- `/en/`, `/pl/` — заглушки «скоро».
- `404.html`

## Персонажі
Спільні олівцеві персонажі лежать у `partials/kit.svg`. Після правки запустити:

    python3 tools/build.py

Скрипт вставляє набір у кожну сторінку між `<!-- kit:start -->` і `<!-- kit:end -->`.

Спільні стилі й поведінка: `assets/comic.css`, `assets/comic.js`.

## Деплой
Cloudflare Pages, підключено до цього репо: кожен пуш у `main` публікується сам. Команда збірки порожня, тека виводу — корінь репо.
